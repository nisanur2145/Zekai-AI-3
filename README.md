# 🧠 Zekai-AI - Akıllı Yardımcınız

Modern, pastel renkli tasarıma sahip AI destekli web sitesi.

## 🎨 Özellikler

- ✨ **Pastel Renk Teması** - Göz yormayan, modern tasarım
- 🤖 **AI Chat** - Canlı sohbet arayüzü
- ⚡ **Next.js 14** - En son teknoloji
- 🎯 **Tailwind CSS** - Responsive tasarım
- 🚀 **GitHub Pages** - Ücretsiz hosting
- 📱 **Mobile Friendly** - Tüm cihazlarda çalışır

## 🛠️ Teknolojiler

- **Frontend:** Next.js, React, Tailwind CSS
- **Styling:** Pastel color palette
- **Animation:** Framer Motion
- **Hosting:** GitHub Pages

## 🚀 Kurulum

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Ürün versiyonu derle
npm run build
npm start
```

## 📍 Deployment

GitHub Pages'e dağıtmak için:

```bash
git push origin main
```

Site otomatik olarak `https://zekai-ai.github.io` adresinde yayına gidecek.
